# Reporting a security problem

If you find a way past the parental lock, a way for a page to read or change Beej's
settings, or anything else that undermines what Beej promises, please do not open a public
issue. Email **info@beejtechnologies.com.np** with:

- what you did, step by step
- what happened, and what should have happened
- your Beej and Chrome versions

You will get a reply, and the problem will be fixed in a release before it is discussed in
public. Credit in the release notes is yours if you want it.

## What is not a security problem

The parental lock guards Beej's settings, not Chrome. These are known and stated in the
[README](README.md#beej-pro-the-parental-lock); report them as ordinary issues if at all:

- removing or disabling the extension in `chrome://extensions`
- using a Chrome profile, guest window or incognito window Beej is not allowed in
- editing extension storage from DevTools
- a self-built copy with the licence check removed
- videos Beej cannot filter yet, listed under
  [Known limits](README.md#known-limits)
